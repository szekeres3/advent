# Adventi informatika

## A projekt felépítése

```
README.md              (ez a fájl)

src                    (forráskód)
|-- index.html         (főoldal)
|-- tasks/             (feladatok)
|   |-- schedule.json  (a feladatok dátumhoz rendelése)
|   |-- minta.md       (mintafeladat)
|   |-- ...
|-- main.js            (DOM módosításhoz)
|-- assets/            (képek, stíluslapok)
|   |-- main.css       (az oldal stíluslapja)

```

## Függőségek

1. Bootstrap 5.3.8
1. markdown-it 15.0.3
1. [Blockflow](https://blockflow.openpatch.org/)

## Célok

> Online felület és feladatok biztosítása, a digitális kultúra tantárgyon belül, a diákok számára az adventi időszakra.
